# TimeCraft

A JavaFX desktop timer application with YouTube Music integration.

## Features

- Countdown timer with `HH:MM:SS` display
- Quick-add time buttons (+5, +10, +30 min, +1 hr)
- Start / Pause / Reset controls
- Embedded YouTube Music via WebView
- Live system clock display
- Visual flash alert when timer reaches zero

## Requirements

- Java 17+
- Maven

## Run

```bash
mvn javafx:run
```
